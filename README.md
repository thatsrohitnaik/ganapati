# Ganpati Quiz & Aarti 🕉️

A simple React app (no backend) with two segments:

1. **Ganpati Quiz** — 50 factual questions about Lord Ganesha in 4 languages: **English, Hindi, Konkani, and Marathi**. Each game picks 10 random questions with score tracking and instant feedback.
2. **Ganpati Aarti** — a collection of Ganpati aartis (सुखकर्ता, अथर्वशीर्ष, गणेश कवच, गजानन स्तुती, विघ्नहर्ता स्तोत्र, गणेश चालीसा) in Marathi.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Data

- `src/data/quizQuestions.json` — 50 quiz questions, each translated into 4 languages
- `src/data/aartis.json` — Ganpati aartis in Marathi

## Build

```bash
npm run build
npm run preview
```
